# snake-water-gun-game
My first python project: a Snake Water Gun game using dictionaries, random module, and conditional statements.

Files : main.py and main_optimized.py

main.py
- Original implementation of the game.
- Uses multiple if-elif conditions to determined the winner.
- Easy to understand for beginners. 

main_optimized.py
- Optimized implementation
- Uses a mathematical pattern (computer-you) to determine the winner.
- Produce the same result with cleaner code.

Features
- Random computer choice
- User input validation
- Display  both user and computer choices
- Announces the winner or a draw

Future Improvements
- Scoreboard
- Play multiple rounds
- GUI version using Tkinter or Pygame
